설치 없이 브라우저에서 바로 돌아가는 단일 HTML 페이지입니다. 서버도, 빌드도 필요 없습니다.

## 다섯 가지 모드

| 모드 | 하는 일 |
| --- | --- |
| **주음읽기** | 기호를 보고 음가(b, p, m…)를 고릅니다 |
| **주음찾기** | 소리와 한글 근사음을 보고 기호를 고릅니다 |
| **성조** | 한자를 보고 올바른 성조 부호를 고릅니다. 힌트는 성조를 뗀 음절만 줍니다 |
| **단어** | 한자 ↔ 뜻 ↔ 주음을 세 방향으로 번갈아 묻습니다 |
| **듣기** | 중국어 음성을 듣고 단어를 고릅니다 |

## 담고 있는 것

**주음부호 59자** — 조음 위치별로 묶었습니다.

- 성모 21 · 개음 3 · 운모 13
- **결합운 22** (ㄧㄚ ㄧㄝ ㄧㄢ ㄨㄛ ㄨㄟ ㄩㄝ …) — 介音은 호박색, 韻母는 자주색으로 칠해 구조가 보입니다
- 한국인이 가장 헷갈리는 **ㄓㄔㄕㄖ(혀말이) ↔ ㄗㄘㄙ(혀평평)** 을 나란히 배치했습니다
- ㄈ와 ㄖ는 한국어에 없는 소리임을 명시합니다

**성조 5개** — 趙元任의 五度標記法 음높이 그래프(55 / 35 / 214 / 51)와 최소대립쌍(媽麻馬罵, 湯糖躺燙, 買賣)을 함께 봅니다.

**일상 단어 105개** — 대만 국어 기준 正體字. 捷運·機車·便當·鳳梨·珍珠奶茶처럼 대만에서만 쓰는 말은 중국 대륙 표현과의 차이를 적어 두었습니다.

## 주음을 배우면 좋은 점

병음은 자음 뒤에서 철자가 바뀝니다. 주음은 바뀌지 않습니다.

| 주음 | 홀로 쓸 때 | 자음 뒤 |
| --- | --- | --- |
| ㄧㄡ | you | -**iu** |
| ㄨㄟ | wei | -**ui** |
| ㄨㄣ | wen | -**un** |
| ㄨㄥ | weng | -**ong** |

앱에서는 이 변화를 결합운 카드마다 표시합니다.

## 발음 들려주기에 대하여

브라우저에 내장된 중국어 음성(Web Speech API)을 씁니다. 기기에 중국어 음성이 없으면 「듣기」 모드만 자동으로 꺼지고 나머지는 그대로 동작합니다.

기호 카드의 윗부분을 누르면 대만 사람이 부호를 읽는 소리(**呼讀音**: ㄅ → ㄅㄛ)가, 아래 「例」 줄을 누르면 예시 단어가 나옵니다. 음가(b)와 읽는 법(ㄅㄛ)은 다릅니다.

**ㄝ · ㄟ · ㄥ 은 국어에서 홀로 한 글자를 이루지 못합니다.** 억지 동음자를 읽히면 엉뚱한 소리가 나므로, 확실히 읽히는 글자로 들려 주고 어느 부분을 들어야 하는지 카드에 적어 두었습니다(ㄝ → 耶의 ㄝ, ㄟ → 杯의 ㄟ, ㄥ → 風의 ㄥ). 결합운은 모두 홀로 설 수 있어 소리가 정확합니다.

## 그 밖에

- **약점 가중치** — 틀린 항목이 더 자주 나옵니다
- **숙련도 기록** — 브라우저 localStorage에 저장되며, 주음표·성조·단어장에서 막대로 봅니다
- **어두운 모드** — 시스템 설정을 따릅니다
- **키보드** — `1`–`4` 선택, `Enter` 다음 문제, `R` 다시 듣기, `Esc` 닫기

## 표기 기준

- 주음부호와 呼讀音은 중화민국 교육부 기준입니다.
- 로마자는 한어병음(漢語拼音)이며, 台北·台灣 등 지명은 통용 표기를 따릅니다.
- 경성 점은 대만식으로 음절 **앞**에 찍습니다 (`ㄒㄧㄝˋ ˙ㄒㄧㄝ`). 한자 오른쪽에 주음을 세로로, 성조 부호는 그 오른쪽에 붙이는 대만 교과서 조판을 그대로 따랐습니다.
- 星期의 期는 대만 독음 ㄑㄧˊ(qí)로 적었습니다.
